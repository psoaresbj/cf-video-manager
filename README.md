# Cloudflare Stream Video Manager

A CLI tool for uploading and managing private videos on Cloudflare Stream. It supports metadata tagging (`title`, `description`, `category`, `owner`), secure token-based playback, and fully interacts with the Cloudflare API — no local storage required.

## Features

- Upload videos to Cloudflare Stream from the terminal
- Set metadata: `title`, `description`, `category`, and `owner`
- List videos via Cloudflare API (supports filters)
- Retrieve secure, token-based playback URLs
- Fully interactive CLI using `Typer`, `Rich`, and `Questionary`

## Requirements

- Python 3.10+
- [`uv`](https://github.com/astral-sh/uv) (install via `pipx install uv`)
- Cloudflare Stream account with an API token (read/write)
- `.env` file with your credentials

## Setup

1. **Clone the repo**
2. **Create a `.env` file** with:
   ```env
   CLOUDFLARE_ACCOUNT_ID=your_account_id
   CLOUDFLARE_API_TOKEN=your_api_token
   CLOUDFLARE_CUSTOMER_SUBDOMAIN=your_customer_code  # Used for preview URL
   ```
3. **Install dependencies**
   ```bash
   uv venv
   source .venv/bin/activate   # or .venv\Scripts\activate on Windows
   uv pip install -r pyproject.toml
   ```

## CLI Usage

```bash
python video-manager.py --help
```

### Upload a video

```bash
python video-manager.py upload path/to/video.mp4
```

Prompts for:

- `title`
- `description`
- `category` (from predefined list)

All values are stored in Cloudflare Stream `meta`.

### List and interact with videos

```bash
python video-manager.py list --search "Video SOP 1" --category manager-tool-updates
```

- Retrieves videos from Cloudflare API
- Filters by category or owner (via `meta`)
- Select a video to preview or delete

### Preview private videos

Generates a secure, signed playback URL via Cloudflare’s `/token` endpoint and shows the final video URL via your customer subdomain.

### Delete a video

Select a video in the list and choose "Delete" to remove it from both Cloudflare and local metadata (if applicable).

## Category Management

Categories are defined in `models/categories.py` as:

```python
from typing import Literal

Category = Literal[
    "manager-tool-updates",
    "misc"
]
```

To add a new category, edit that file and append a new string.

## Security

- Videos are uploaded with `requiresignedurls=true`
- Playback requires a signed token
- Tokens are generated by the CLI using your Cloudflare API credentials

## Tags / Metadata

Cloudflare allows arbitrary key:value metadata (e.g., `category`, `owner`, etc). These are stored under `meta` and searchable via the API.

See Cloudflare docs:
- https://developers.cloudflare.com/stream/uploading-videos/metadata/
- https://developers.cloudflare.com/api/operations/stream-list-videos
